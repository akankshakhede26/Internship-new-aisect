# AdminFlow — Responsive Admin Dashboard

A student mini-project built with React, Vite, React Router, Tailwind CSS, and Context API.

## Features
- Dashboard, Users, Reports, and Settings pages
- Client-side navigation with React Router
- Light/dark theme shared using Context API
- Responsive mobile sidebar
- Reusable analytics cards and CSS-only charts
- Search and status filtering on the Users page
- Demo data only; no backend or real account actions are connected

## Run locally
```bash
npm install
npm run dev
```
Open the localhost URL printed by Vite in your terminal.

## Production build
```bash
npm run build
npm run preview
```

## Included local assets
- `public/assets/adminflow-mark.svg` — AdminFlow brand mark and browser favicon.
- `public/assets/admin-avatar.svg` — local placeholder profile avatar for the sidebar.
- `public/assets/empty-reports.svg` — reusable reports illustration for future UI updates.

All three assets are stored locally; the dashboard does not need remote image URLs for these assets.
