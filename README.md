# AISECT Web Development Internship

This repository contains all the tasks, exercises, and projects completed during the AISECT Web Development Internship.

## Weekly Tasks Overview

- **week 1 tasks/**: HTML5, CSS3, JavaScript basics, and Personal Portfolio website.
- **week 2 tasks/**: DOM manipulation, Event handling, LocalStorage, and Task Manager app.
- **week 3 tasks/**: React fundamentals, components, props, state management, and Personal Blog app.
- **week 4 tasks/**: React Router, Context API theme switcher, and Tailwind CSS landing pages.

## Projects

- **Week 1 Mini Project**: Personal Portfolio (`week 1 tasks/mini_project`)
- **Week 2 Mini Project**: Task Manager Web App (`week 2 tasks/mini_project 2`)
- **Week 3 Mini Project**: Personal Blog React App (`week 3 tasks/mini_project 3`)
- **Week 4 Projects**: Tailwind CSS Landing Pages (`week 4 tasks/tailwind-day4`)

## How to Run

### HTML, CSS & JavaScript
Open `index.html` from any task folder in your browser.

### React & Tailwind Projects
Navigate to the project folder and run:
```bash
npm install
npm start
```
Or for Vite projects:
```bash
npm run dev
```
